# Migrating from v0.9.x to v1.0.0

**Status:** Draft — apply only when [ROADMAP Phase 9](https://github.com/eddiethedean/ontologos/blob/main/ROADMAP.md#phase-9--v100-tag-100-in-scope-parity) exit criteria are met.

## When 1.0.0 ships

OntoLogos **1.0.0** means full HermiT replacement readiness per the [ROADMAP](https://github.com/eddiethedean/ontologos/blob/main/ROADMAP.md), not a cosmetic semver bump. The tag is created only when **Phase 9** completes:

- `parity_pct = 100%` — zero `planned` Java + WG catalog cases (`check-hermit-parity-phases.sh`)
- [Phase 8](https://github.com/eddiethedean/ontologos/blob/main/ROADMAP.md#phase-8--expressivity-prerequisites-v15v19) — v1.5–v1.9 expressivity tracks complete
- `ontologos-dl` stable on crates.io (not preview)
- HermiT Tier A + B + C conformance **blocking** in CI
- `check-1.0-release-gates.sh` **blocking** in CI (not informational)

Passing `check-1.0-release-gates.sh` alone (≥400 active tests) is **insufficient** — catalog parity can be ~58% while that script passes.

## Expected API changes

| Area | v0.9.x | v1.0.0 |
|------|--------|--------|
| `Profile::Auto` | Single-engine pick; DL → whole ontology | MORe-style hybrid EL + DL module routing |
| `Profile::Dl` | Preview warning via `--profile dl-preview` | Stable default for DL ontologies |
| `ontologos-dl` | crates.io preview | Stable workspace + crates.io dependency |
| JSON snapshot | v2 | v3 (ABox literals, negative assertions; v2 read supported) |
| CLI | `classify`, `materialize`, `explain` | Adds `query` for OWL QL |

## Python / Rust version pins

All `ontologos-*` crates and the PyPI wheel bump together to `1.0.0`.

## Conformance

**593** active conformance tests today (target was ≥400 for interim gates). Full parity requires clearing **397** planned catalog cases per [parity phases](https://github.com/eddiethedean/ontologos/blob/main/ROADMAP.md#hermit-parity-phases-path-to-v100-tag). Ignored test budget shrinks monotonically (`check-hermit-ignore-budget.sh`).

## If you depend on 0.9.x preview behaviour

- Pin `ontologos = "0.9"` in Cargo.toml or `ontologos==0.9.*` on PyPI.
- Use explicit `--profile el` / `--profile rl` instead of `auto` until hybrid routing is validated on your corpus.

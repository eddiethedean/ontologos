> **Install**
>
> Latest release is **v1.1.4** on [crates.io](https://crates.io/crates/ontologos-core), [PyPI](https://pypi.org/project/ontologos/), and [Wasmer](https://wasmer.io/eddiethedean/ontologos).
>
> | Install command | Profiles available for production |
> |-----------------|----------------------------------|
> | `pip install ontologos` or `ontologos-* = "1.1.4"` | EL, RL, RDFS, **DL**, **SWRL** |
> | WASM: [eddiethedean/ontologos](https://wasmer.io/eddiethedean/ontologos) | Same (JS glue from `crates/ontologos-wasm`) |
>
> Preview profiles (`alc`, `dl-preview`) remain experimental. See [Profile stability](/guides/profile-stability/).
>
> Node, Java, .NET, C/C++ bindings: [Bindings overview](/guides/bindings-overview/) (source-build).

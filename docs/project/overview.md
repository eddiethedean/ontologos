# Project Overview

OntoLogos is a modular Rust ontology reasoner for OWL EL, RL, and RDFS — embeddable in Rust and Python pipelines.

**Workspace version:** 0.8.0 · **Latest tagged release:** **v0.7.0** · **v0.8.0** ready on `main` (tag pending). See the [documentation home](../index.md) for capability matrix, learning path, and guides.
